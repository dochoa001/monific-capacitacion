# Capacitación HubSpot · Monific

Material de apoyo para el equipo de Monific, preparado por Black & Orange.

- **Repaso por módulo** (`repaso.html`): cuestionario de seis preguntas para cada uno de los nueve módulos de la capacitación. Cada respuesta explica el porqué y dónde repasarlo en el Manual operativo o la Base de conocimiento.
- **Mapa de una página** (`mapa.html`): cómo se conecta todo en el portal — recorrido de una campaña, tipos de ticket, cobranza antes y después del vencimiento, los cinco objetos y las reglas básicas.

Las páginas se abren en cualquier navegador y no guardan datos fuera del propio navegador de quien las usa. No están indexadas en buscadores.
